# Architecture

```text
GitHub Repository
       |
       v
GitHub Ocean
       |
       v
Port Catalog
       |
       +--> Repository
       +--> Branch
       +--> Pull Request
       +--> Issue
       +--> Workflow
       +--> Workflow Run
       +--> Environment
       +--> Deployment
       +--> Release
       +--> Tag
       +--> Security alerts
       +--> Collaborators / Teams
```

The repository is intentionally small but contains enough configuration and
automation to generate multiple GitHub resource types.
